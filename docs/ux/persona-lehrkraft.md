# UI vs. UX

**UI (User Interface):** das sichtbare Erscheinungsbild – Farben, Buttons, Layout, Typografie.
*Beispiel Classroom-Manager:* die bereits erstellten Info-Karten „Klassen / Anwesenheiten / Kursbuch" auf der Landing-Page. Dazu ihre Farben und Anordnung.

**UX (User Experience):** wie leicht, verständlich und angenehm sich die Nutzung insgesamt anfühlt.
*Beispiel Classroom-Manager:* wie schnell eine Lehrkraft während der Stunde die Anwesenheit seiner Klasse erfassen kann, ohne den Unterricht zu lange aufzuhalten.

Der Classroom-Manager kann ein gute/schöne UI haben und trotzdem eine schlechte UX, wenn z. B. das Erfassen der Anwesenheit sehr viele Klicks braucht.

## Ziele im Schulalltag

1. Anwesenheiten pro Stunde in unter einer Minute erfassen, ohne den Unterrichtsfluss zu unterbrechen.
2. Auf einen Blick sehen, wie sich eine Klasse (z. B. FI24A) über das Halbjahr entwickelt hat (z.B. Anwesenheiten über Zeitraum, Lerninhalte usw.)
3. Kursbuch-Einträge (behandelte Themen) direkt nach der Stunde festhalten, statt sie sich für später zu merken.
4. Bei Elterngesprächen oder Konferenzen schnell belastbare Zahlen zu einzelnen Schüler:innen vorlegen können.

## Frustpunkte (Ist-Zustand)

1. **Excel-Insellösungen:** jede Kollegin führt ihre eigene Anwesenheits-Tabelle, Formate und Spalten unterscheiden sich, keine Einheitlichkeit.
2. **Medienbrüche:** Anwesenheit wird auf Papier erfasst, abends in Excel übertragen, Kursbuch läuft in einem dritten System – dreifache Arbeit für dieselbe Information.
3. **Kein Verlauf sichtbar:** Excel zeigt nur den aktuellen Stand, keine Tendenz („Wird die Anwesenheit von Max in FI24A schlechter?") ohne manuelle Auswertung.
4. **Fehleranfällig unter Zeitdruck:** Namen werden während der Stunde schnell verwechselt oder vergessen einzutragen, weil die Erfassung zu viele Schritte braucht.

## Bezug zum Classroom-Manager

Frida ist die primäre Nutzerin der drei Kernbereiche des Classroom-Managers:

- **Klassen:** sieht FI24A und FI24B mit ihren Schülern auf einen Blick.
- **Anwesenheiten:** erfasst pro Stunde und Klasse, statt in einer privaten Excel-Datei.
- **Kursbuch:** dokumentiert Unterrichtsinhalte direkt im System statt in einem separaten Heft.
